    Names read correctly

    Every name is set apart from the text around it, so Hebrew names keep their order next to English words, separators and numbers.

    Colour means something

    Buttons and tabs are ink. Blue, purple and orange only ever mean a network, teal the route, amber a highlight, dashed a proposed object.

    Hardware looks like hardware

    Racks, faceplates and HDFs are the only dark things, with names on label strips. A 1U row never shrinks below a readable height; tall racks scroll.

    The same system for what comes next

    The map overview and the inventory use the same paper, ink, chips and names. The inventory keeps its approved portal layout; only network dots carry colour.

    One way to do each thing

    One chip, one form layout (labels above, two columns), three buttons. Text is never below 11px, and only jack numbers use that size.
