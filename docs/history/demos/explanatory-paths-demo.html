DEMO
Proposed walk sheet and uplinks summary. Fictional data that lives only in this page; nothing is saved.
  1. On the switch page, the Uplinks box lists every port that reaches an AGG or BB. Click a line to see its walk sheet on the right.
  2. Click any port on the faceplate: you get its walk sheet wherever it ends (an AGG/BB, another switch, a free end, or no cable).
  3. Click a row of the walk sheet: a switch opens its own page; other rows say where they would open in Physical.
  4. Compare with today shows the current hop list for the same path. Conceptual in the header shows the walk sheet inside the Find AGG / BB results; turn on Route view there for the new route picture.
The map itself is unchanged in this demo; only the results panel is new.

What changes from today

  • One row per equipment, grouped by place (Site › Node › Rack, with the unit). A passive bridge is folded into its row as “in front 2 → out rear 2”; there is no separate PANEL BRIDGE row.
  • Cables show their label when it is set. Without a label they show the last six characters of the ID; hover for the full ID.
  • When a cable leaves a node or a site, the sheet says so (“leaves בניין 12 – מעבדות”).
  • Hebrew names are kept whole and in their own direction, so “HDF-צפון-01 · 3C/5” never mixes with the position next to it.
  • The same uplinks summary also appears in the inspector when a switch is selected on the map.
  • Route view (Conceptual, in the results) is redrawn: each node is a box holding its steps close together, nodes are far apart inside their site's frame, and a cable that leaves a node or site is long and says so. The trace is one thick line with arrows and a moving flow, joining the ports used at each end. PNG and PDF export this picture.
  • No server change: everything is built from the trace result and the inventory the page already has.
